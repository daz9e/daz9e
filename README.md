### Hi, I'm Pavel 👋

Backend developer from Belgrade, mostly PHP and Laravel, with a bit of Go and Rust.

Outside of work I self-host pretty much everything I can and tinker with it on my home server.
I like odd problems that don't have a ready-made answer, and I tend to rebuild the tools I use
when I notice they could work better.

- [simd](https://github.com/daz9e/simd): minimal self-hosted Markdown viewer in Rust
- [laravel-log-compressor](https://github.com/daz9e/laravel-log-compressor): Laravel package that gzips rotated logs and cleans up old archives
- [pi-git-sync](https://github.com/daz9e/pi-git-sync): syncs Pi coding agent config across machines through Git
